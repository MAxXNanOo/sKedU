    1.รันคำสั่งตามนี้

    git add . (ถ้าจะเอาลง git ทุกไฟล์)  or  git add ชื่อไฟล์ (เอาลงเเค่บางไฟล์ มากกว่า1ก็ทำหลายๆครั้ง)
